# 🚄 Train Tracker — Cyberpunk Edition

A sleek Cyberpunk-styled Amtrak train schedule tracker built with HTML, CSS, and JavaScript.

## 🚀 Live Demo
[View Live App](https://starlit-trifle-84802b.netlify.app/train-tracker.html)

## ✨ Features
- Live train schedule board
- Filter by route and status
- Animated route map with live train icon
- Statistics tab with on-time performance bars
- Multiple Amtrak routes included
- Refresh button randomizes statuses
- Cyberpunk neon design with glitch effects

## 🛠️ Technologies Used
- HTML5
- CSS3 (Custom Cyberpunk theme)
- JavaScript (Vanilla)

## 📱 How To Use
1. Select a route or status to filter trains
2. Tap Schedule, Map or Statistics tabs
3. Hit Refresh to update train statuses
